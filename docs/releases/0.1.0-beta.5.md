# Knitt 0.1.0-beta.5

- Adds project-scoped cross-agent history discovery for Codex, Claude Code and Antigravity, with source labels and the four newest matches.
- Adds the `/knit` native question picker with explicit acceptance, cancellation, workspace validation and stale-choice rejection.
- Returns bounded context with conversation acceptance, removing an extra model/tool round trip. Uses the startup session and current folder directly before opening the picker; older servers retain a context fallback.
- Registers project-specific Antigravity MCP servers globally and verifies their tools. Setup, update, rollback and uninstall preserve unrelated registrations.
- Preserves opt-in conversation capture, session capabilities, checkpoint citations, source isolation, schema compatibility guards and the `/continue-chat` workflow already on master.
- Normalizes physical workspace aliases for history matching and stable Antigravity server identity across macOS and Windows path spellings.
- Includes native Windows/macOS/Linux setup and expanded installed-package lifecycle checks.

Validation: type checking, 109 automated tests, and installed-package smoke checks passed locally. The archive lifecycle covers legacy and opt-in capture, checkpoints, handoff, update, rollback, failed-install preservation and uninstall. Upgrade and rollback against the actual published beta.3 archive passed for both legacy and opt-in projects. Platform CI is required before release.

Latency measurements use a local MCP connection and exclude model thinking and UI rendering. Integrated release measurements: list 68–143 ms; selection including context 5–21 ms. These are samples, not an end-to-end response-time guarantee.

Upgrade: `npx --yes @tinchu0/knitt@latest update --yes`, using the same `--home` as the existing installation when customized. Restart connected coding clients after updating. Both `latest` and `next` point to this beta by release policy.
